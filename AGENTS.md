# Release handoffs

After every published release, update the private HANDOFF.md and write a dated
session summary before reporting completion. Record the release version, source
commit, artifacts, deployment state for each configured computer, verification
results and outstanding work. Sync these private resume documents to the other
configured Mac when reachable; otherwise record that sync as pending.

Keep handoffs, session transcripts, credentials and machine-specific diagnostics
out of public commits. Preserve unrelated local files. Use feature branches and
concise pull requests for release changes.
